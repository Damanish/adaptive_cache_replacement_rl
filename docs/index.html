Formulation & parameters

An episode is one trace. Each step covers W=100 requests, which makes the problem a semi-MDP over decision windows. All values below come from the code and the trained checkpoints.

State 𝒮 ⊂ ℝ

Computed only from past windows; the same layout is used for 3 and 4 actions.

Action 𝒜 (discrete)

3-action setting: {LRU, LFU, FIFO}. 4-action setting: adds MRU. The action sets the victim rule for every miss in the next window. Policy switches never flush the cache.

Reward ℛ

rt = 2 (ht − htLRU) − λ · 𝟙[at ≠ at−1]

ht is the agent's hit rate in window t, and htLRU is the hit rate of a shadow LRU cache on the same window. The shadow term does not depend on the agent's actions, so subtracting it lowers variance without changing the optimal policy. λ = 0 in all experiments. Also implemented: hit/miss 2ht−1 and latency −AMATt/Lmiss.
